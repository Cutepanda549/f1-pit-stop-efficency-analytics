# F1 Pit Stop Efficiency & Track Position Impact (2026 Season)

An end-to-end Python data analysis pipeline examining how Formula 1 pit crew execution and pit-lane time loss translate into net track position gained or lost during green-flag race cycles.

## The Racing Problem
In modern Formula 1, on-track overtaking is heavily constrained by dirty air and track layout, making pit road one of the highest-leverage environments for gaining track position. However, raw stationary tire-change times only tell part of the story. This project quantifies **total pit-lane time loss** (entry, stationary service, and exit) across constructors and evaluates how consistency in pit execution directly impacts race outcomes and undercut success.
